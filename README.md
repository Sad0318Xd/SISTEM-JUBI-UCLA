Para poder poner en prueba el sistema debe importar la base de datos llamada "su_jubi_db.sql". Al importarla debe colocar el mismo nombre para que la conexión la reconozca rápidamente sin inconvenientes.

Por último para acceder al inicio de la página debe localizar la carpeta del projecto ya alojada en la carpeta htdocs de xampp, una vez allí debe abrir desde la url de la web la carpeta llamada "public", desde ahí tendra acceso al inicio de la página web.
